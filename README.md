# POSTLOGIX AI Website

Hackathon-ready static frontend prototype.

## Included
- Parcel/adress data form
- Validation
- AI-ready address processing stage
- Post office identification demo
- Map-style result panel
- AI feature cards

## Deploy on Vercel
Import this folder/repository into Vercel. No build command is required for the static prototype.

## Production AI
Keep your Gemini/Hugging Face API key on a backend (FastAPI/Flask), not inside browser JavaScript.
